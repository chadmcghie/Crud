## Documentation Best Practices

### Naming Conventions
- **Files**: `kebab-case.md`
- **Folders**: `01-folder-name/` (numbered by priority)
- **Decisions**: `YYYY-MM-DD-ADR-XXX-title.md`
- **Development Choices**: `YYYY-MM-DD-DC-XXX-title.md`
- **Technical Debt**: `YYYY-MM-DD-TD-XXX-title.md`

### Registry Pattern
Major sections include registry.md files for chronological tracking and cross-referencing.

### Gap Identification
.gaps folders identify missing documentation with .gap files for future planning.
